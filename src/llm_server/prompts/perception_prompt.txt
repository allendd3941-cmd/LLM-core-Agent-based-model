## 任務

把下方「回傳環境內容」payload 整理成精簡、給駕駛決策用的結構化資料：一份全域環境 +
每個 agent 一筆。所有欄位都已是算好的質性資訊，照原樣搬進對應位置；嚴格依下面的 JSON 範本輸出。

## 規則

1. 只依 payload 內容整理，不發明、不推測，也不還原已刪減的欄位。
2. `environment`、`agent.environment`、`short_term_memory`、`long_term_memory` 已是精簡好的質性欄位，
   照原樣搬進對應位置（欄位意義見範本的 placeholder）。
3. 每個 agent 一筆，以 `agent_id` 識別，不可漏。
4. 每筆 `summary_text` 用繁體中文一句話，點出該 agent（或全市）目前狀態與移動趨勢；
   `route_status` 為 `arrived` 要說明已抵達、為 `waiting_for_api_origin` 要說明尚未完成生成地套用；
   記憶為空就說明尚無旅行記憶。
5. 欄位不存在就略過（不要自行補值）；存在但為空字串/null/空陣列要保留。
6. 只輸出合法 JSON，不要 Markdown、不要 ```json、不要尾逗號、不要任何解釋文字。不要輸出 active mode 決策。
