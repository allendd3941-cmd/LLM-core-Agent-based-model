輸出規則：
1. 只輸出合法 JSON，不要解釋、註解或 markdown，請輸出具備換行與縮排的巢狀 JSON，不要壓縮成單行。。
2. 最外層只能是一個 JSON object，且只包含一個欄位 "agents"。
3. "agents" 必須是 JSON array，內含指定數量的 agent object。
4. 每個 agent object 只能包含 "identity" 與 "traits" 兩個欄位。
5. 每個 value 都必須是自然語言，不要只放代碼、數字或縮寫。
6. 除 residential_location 外，identity 各欄位請用十個字以內的中文片語描述。
7. residential_location 請填台南市實際存在的行政區，例如「安平區」。
8. name 請填中文姓名，例如「黃俊祺」。
9. traits 中 attitudes、habits、decision_making_tendencies、economic_preferences_and_tradeoffs 各欄位皆為 array，內容請用十個字以內的中文片語描述。
10. "vehicle_ownership"的值只能為「機車」或「汽車」。

輸出結構範例如下：

{
  "agents": [
    {
      "identity": {
        "name": "黃俊祺",
        "age": "二十歲左右",
        "occupation": "大學生",
        "wage": "每月打工四萬",
        "vehicle_ownership": "機車",
        "residential_location": "安平區"
      },
      "traits": {
        "attitudes": ["願意遵守交通規則"],
        "habits": ["習慣提早到球場"],
        "decision_making_tendencies": ["常依現場人潮調整"],
        "economic_preferences_and_tradeoffs": ["偏好省錢停車選擇"]
      }
    }
  ]
}
